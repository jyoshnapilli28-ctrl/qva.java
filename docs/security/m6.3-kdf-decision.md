# M6.3 KDF and runtime decision

Format 1 uses the platform Web Crypto API. PBKDF2-HMAC-SHA-256 uses 600000 iterations and a fresh 128-bit salt. AES-256-GCM uses a fresh 96-bit nonce and a 128-bit tag. Randomness comes from crypto.getRandomValues, and local P-256 key creation from crypto.subtle.generateKey. Code adds no cryptographic package, npm dependency or lockfile change. Browser engine implementations and versions need to be validated by runtime. No FIPS claim is made. The OWASP iteration guidance is a reference point, and offline attack resistance also depends on a strong independent passphrase.

| Candidate | Review result |
| --- | --- |
| Argon2id via @noble/hashes | Upstream offers MIT licensed pure JS Argon2id for JavaScript runtimes and current npm metadata shows version 2.4.0. Upstream's cited early audit explicitly excluded Argon2. The exact release tarball and QVA browser test evidence were unavailable, so no Argon2 dependency was added. |
| Argon2id via hash-wasm | A Wasm candidate considered for a later pinned review. No exact supply-chain, provider audit and browser evidence adequate for integration were established in this sprint. |
| Browser-native PBKDF2 and AES-GCM | Selected for this explicit version. Uses standardized browser primitives and HTTPS/loopback secure-context checks. Code never switches algorithms based on untrusted vault input or platform failure. Crypto, Workers, IndexedDB, BroadcastChannel and Web Locks are required. |

Node 24.22.1 native Web Crypto in the Linux development environment measured 144.3, 158.0, 156.5, 164.3 and 208.1 ms for five single key derivations (median 158.0 ms). First setup derives twice so it can check the newly encrypted record before committing it. Timing is local evidence and varies with hardware and other load. A separate Linux Chrome Headless Shell 131 probe with the default feature set measured 248.5, 207.4, 193.3, 167.8 and 186.3 ms (median 193.3 ms). Chrome 131 also reported NotSupportedError for native Ed25519, including with the experimental feature name requested. Local-only P-256 permits testing without that runtime feature and leaves the selected MLS suite and the Ed25519 server credential contract unchanged. Chromium 156 could not start because the workspace rejected its process-singleton socket. Windows was unavailable for benchmarking. Choose the Argon2 provider on maintenance, pinning, licensing, advisories, reference vectors and Windows runtime measurements before any format migration. A migration must authenticate the old vault and write the new encrypted format atomically.
